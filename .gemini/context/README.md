# Context Engineering

Este diretório gerencia o **Contexto Arquitetural** do agente e do sistema:

- **project_state.md**: Estado atual das decisões, objetivos e marcos do projeto.
- **domain_knowledge.md**: Conceitos-chave de negócio, infraestrutura e arquitetura de IA acumulados.
- **working_memory.md**: Contexto temporário de sessões ativas e referências a problemas em resolução.

> **Objetivo**: Evitar degradação de contexto (*context drift* / *context dilution*), perda de fatos críticos e consumo excessivo de tokens.
