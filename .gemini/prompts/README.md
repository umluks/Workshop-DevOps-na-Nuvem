# Prompt Engineering & System Personas

Este diretório armazena **Prompts Versionados** e **Personas Especializadas**:

- **system_prompts/**: Prompts-base de instrução de sistema (System Instructions) para diferentes papéis (ex.: Arquiteto Cloud, Revisor IaC, Engenheiro de IA).
- **few_shots/**: Exemplos canônicos de entrada e saída (Golden Examples) para guiar o raciocínio do modelo.
- **templates/**: Templates parametrizáveis de prompts para tarefas recorrentes (ex.: geração de ADRs, análise de logs, model evaluation).

> **Objetivo**: Tratar prompts como código (Prompt-as-Code), permitindo versionamento Git, testes de regressão e evolução controlada.
